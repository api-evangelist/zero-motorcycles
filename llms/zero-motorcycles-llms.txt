# Zero Motorcycles

> Zero Motorcycles is an American manufacturer of electric motorcycles and powertrains,
> founded in 2006 in Santa Cruz, California. Its bikes run the Cypher operating system,
> which pairs with the Zero Motorcycles NextGen mobile app for ride data, remote
> diagnostics, over-the-air updates and performance customization. Zero publishes no
> public developer program, API documentation, SDK, or machine-readable specification —
> its connected-vehicle surface is consumer-facing only.

## APIs

No public API. Zero Motorcycles operates a Cypher Store backend at
`api-cypherstore.zeromotorcycles.com` that serves the NextGen mobile app, but it is
undocumented, unadvertised, and returns the same placeholder HTML page for every path
including nonsense control paths. There is no developer portal, no OpenAPI or AsyncAPI
document, no GraphQL endpoint, no MCP server, and no A2A agent card on any Zero host.
